같이 꽂기

-----

    방을 만들고 초대 링크를 보내면, 친구가 꽂는 이미지가 모두의 케이크에 바로 꽂혀요.

    이미지 찾기

    1. 검색하면 옆에 검색 창이 열려요.
    2. 마음에 드는 이미지를 케이크로 끌어다 놓거나, 우클릭 > 이미지 복사 후 여기서 Ctrl+V.
    검색 창에 케이크에 꽂기 버튼 띄우기

    아래 버튼을 북마크바로 끌어다 두세요. 검색 창에서 그 북마크를 한 번 누르면, 이미지에 마우스를 올릴 때 케이크에 꽂기 버튼이 떠요. 이 사이트의 검색 버튼으로 연 창에서만 동작해요.
